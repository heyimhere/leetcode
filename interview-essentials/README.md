# Interview Essentials

100 blank problems for daily reps — the description, the examples, the
constraints, and an empty stub. No solutions and no hints. Solve it cold,
then compare against the solved copy in the main repo.

```bash
node interview-essentials/001-two-sum.js
```

Running an unsolved file prints `undefined` for each case — that is expected.
Every file is standalone; linked-list, tree and graph problems carry their own
node classes and array helpers so the test lines stay readable.

Numbers are LeetCode problem numbers. The `k` prefix marks Karat-style
problems, which have no LeetCode equivalent.
